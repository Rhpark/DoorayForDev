# Dooray 위키 목록

먼저 저장소 루트의 `DOORAY.md`를 읽고 공통 실행 규칙을 따른다.

저장소 루트에서 다음 명령을 실행한다. 경로가 없으면 인자 없이 전체 트리를 조회하고, 경로를 주면 그 아래만 조회한다.

```text
dooray wiki-list 선택적-"경로"
```

경로는 `>` 앞뒤를 공백 한 칸으로 맞추고(`회의록>LG` → `회의록 > LG`) 따옴표로 감싼다. Windows `dooray` launcher는 공백 없는 `>`를 리다이렉션으로 해석한다.

원본 결과만 그대로 즉시 보여준다. 요약하지 않는다. 도구 출력 상자는 터미널이 접을 수 있으니, 결과 전체를 답변 본문 코드블록에 붙여넣는다.

하위 페이지가 없다는 메시지와 없는 경로·중복 제목 등의 오류도 그대로 전달한다.
