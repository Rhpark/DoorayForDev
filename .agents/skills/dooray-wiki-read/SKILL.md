# Dooray 위키 읽기

먼저 저장소 루트의 `DOORAY.md`를 읽고 공통 실행 규칙을 따른다.

1. 저장소 루트에서 다음 명령을 실행한다. 경로는 `>` 앞뒤를 공백 한 칸으로 맞추고(`Visualizer>` → `Visualizer >`) 따옴표로 감싼다. Windows `dooray` launcher는 공백 없는 `>`를 리다이렉션으로 해석한다. 경로가 없으면 인자 없이 실행하고, 끝이 `>`면 해당 페이지 아래를 탐색한다.

```text
dooray wiki-read 선택적-"경로"
```

2. 출력의 둘째 줄이 `  1. 제목` 형태면 탐색 단계다. 첫 줄(현재 경로)과 번호 목록 전체를 답변 본문의 코드블록으로 보여주고, 목록 끝에 `0. 여기 읽기`를 덧붙여 번호나 제목으로 고르게 한다. 목록을 일부 선택지로 줄이지 않고 사용자의 답을 기다린다.
   - 하위 페이지를 고르면 `"<첫 줄 경로> > <고른 제목> >"`로 다시 실행하고 2번을 반복한다.
   - `0. 여기 읽기`를 고르면 `"<첫 줄 경로>"`(끝 `>` 없이)로 실행한다.
3. 하위 페이지가 없으면 끝에 `>`를 붙여도 읽기 결과가 나온다. 본문·댓글·파일 목록·위키 주소를 포함한 원본 전체를 답변 본문 코드블록으로 보여준다. 본문이 비어 있어도 댓글을 생략하지 않고, 내용을 요약하거나 재작성하지 않는다.

파일 다운로드를 요청하면 다음 명령을 실행한다. 번호는 읽기 결과의 파일 목록 번호이고, 파일명·번호·all을 생략하면 전체를 받는다.

```text
dooray wiki-download "첫 줄 경로" 선택적-파일명-또는-번호-또는-all
```

다운로드 결과와 저장 경로를 그대로 전달한다. 저장 위치는 `Dooray/wiki/<위키이름>/<제목>/.../download/`다.

없는 경로나 같은 제목이 여럿인 오류는 그대로 알린다. 오류에 하위 페이지 목록이 있으면 그 목록에서 다시 고르게 할 수 있다.
