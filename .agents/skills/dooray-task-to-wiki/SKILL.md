# Dooray 업무 → 위키 문서

업무 하나를 읽고, 그 업무를 모르는 개발자·엔지니어가 사용할 위키 문서를 작성한다.

1. 저장소 루트의 `DOORAY.md`를 읽는다.
2. `.claude/skills/dooray-task-to-wiki/references/task-to-wiki-workflow.md`의 자료 확인 → 초안 작성·검토 → 위치 선정 → 게시 확인·업로드 절차를 따른다. 경로는 저장소 루트 기준이다.
3. 초안은 `apply_patch`로 생성·수정한다. 이미지는 이미지 보기 도구로 직접 확인하고, PDF와 기타 첨부는 현재 도구로 실제 판독한 범위만 근거로 사용한다.

자료 조회와 게시에는 저장소 루트의 `dooray` CLI를 사용한다. 실제 게시 전의 명시적 확인은 공통 절차에서 받으며, 도구 실행 승인창의 표시 여부는 Codex 실행 환경의 권한 정책을 따른다.
